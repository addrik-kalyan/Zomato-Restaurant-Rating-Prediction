# Zomato Restaurant Rating Prediction

A machine learning project that predicts restaurant ratings using the Zomato dataset. The model analyzes features such as location, cuisine type, average cost, and online delivery options to estimate customer ratings.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Project Goal
To build a regression model that predicts restaurant ratings based on restaurant features.

## Features
- Data cleaning and preprocessing
- Feature encoding
- Model training and evaluation
- Rating prediction for new restaurant data

## Dataset
The Zomato dataset contains information about restaurants, including cuisine types, costs, delivery options, and ratings.
